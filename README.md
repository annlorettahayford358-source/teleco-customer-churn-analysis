# teleco-customer-churn-analysis
Customer churn analysis project using SQL, Excel, Power BI, R, and Python.

## Project Overview
This project analyzes customer churn behavior to identify factors that contribute to customer retention and customer loss.

## Business Problem
Every company loses customers. The goal of this project is to identify customer behaviors that predict churn and provide data-driven retention recommendations.

## Focus Areas

- Customer tenure
- Contract type
- Monthly charges
- Service usage

## Tools Used
- SQL (BigQuery)
- Excel
- Power BI
- R Programming
- Python (Kaggle)

## Key Insights
- Month-to-month contracts experience the highest churn.
- Customers within their first year are highest risk.
- Higher monthly charges increase churn likelihood.
- Customers without support services churn more frequently.
